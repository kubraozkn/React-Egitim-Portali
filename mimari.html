Bileşen Tabanlı Mimari

Bileşen Tabanlı Mimari Nedir?

Bileşen tabanlı mimari, yazılım geliştirmenin modüler ve yeniden kullanılabilir bileşenler etrafında organize edildiği bir yaklaşımdır. Bu mimari, yazılımın farklı bölümlerini bağımsız ve bağımlılıktan arınmış bileşenler olarak tasarlamayı ve geliştirmeyi hedefler.

React, bileşen tabanlı mimarinin popüler bir örneğidir ve bileşenler aracılığıyla kullanıcı arayüzlerinin oluşturulmasını kolaylaştırır.

Bileşen Tabanlı Mimari'nin Avantajları

  • Modülerlik: Kodun modüler yapıda olması, bileşenlerin bağımsız olarak geliştirilmesini ve test edilmesini sağlar.
  • Yeniden Kullanılabilirlik: Bileşenler, birden fazla proje veya uygulama içinde tekrar tekrar kullanılabilir.
  • Bakım Kolaylığı: Bileşenler, bağımsız ve izole olduğu için kodun bakımını ve güncellenmesini kolaylaştırır.
  • Test Edilebilirlik: Bileşenler, bağımsız olarak test edilebilir, bu da hata tespiti ve düzeltmeyi kolaylaştırır.
  • İşbirliği: Ekipler, farklı bileşenler üzerinde paralel olarak çalışabilir ve proje ilerlemesini hızlandırabilir.

React Bileşenleri

React, bileşen tabanlı mimariyi uygulamak için kullanılan popüler bir JavaScript kütüphanesidir. React bileşenleri, kullanıcı arayüzlerinin temel yapı taşlarıdır ve iki ana türde olabilir: Fonksiyonel Bileşenler ve Sınıf Bileşenleri.

Fonksiyonel Bileşenler

Fonksiyonel bileşenler, bir JavaScript fonksiyonu olarak tanımlanan basit bileşenlerdir. Hook'lar kullanılarak state ve diğer React özellikleri eklenebilir.

Örnek:

<script>
        function Merhaba(props) {
            return <h1>Merhaba, {props.isim}</h1>;
        }
        
        const App = () => (
            <div>
                <Merhaba isim="Dünya" />
            </div>
        );
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Sınıf Bileşenleri

Sınıf bileşenleri, bir JavaScript sınıfı olarak tanımlanan daha karmaşık bileşenlerdir. React'in lifecycle metodları ve state yönetimi için kullanılabilir.

Örnek:

<script>
        class Merhaba extends React.Component {
            render() {
                return <h1>Merhaba, {this.props.isim}</h1>;
            }
        }
        
        class App extends React.Component {
            render() {
                return (
                    <div>
                        <Merhaba isim="Dünya" />
                    </div>
                );
            }
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Bileşenler Arası İletişim

React bileşenleri, props ve state kullanarak birbirleriyle iletişim kurar.

Props Kullanımı

Props, bileşenler arasında veri taşımak için kullanılır. Üst bileşenden alt bileşene veri aktarımını sağlar.

Örnek:

<script>
        function Selam(props) {
            return <h1>Merhaba, {props.isim}</h1>;
        }
        
        function App() {
            return (
                <div>
                    <Selam isim="Dünya" />
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
State Kullanımı

State, bir bileşenin durumunu ifade eder ve bileşenin yeniden render edilmesine neden olur. State, bileşen içinde yönetilir ve güncellenir.

Örnek:

<script>
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => setCount(count + 1)}>Artır</button>
                </div>
            );
        }
        
        function App() {
            return (
                <div>
                    <Sayaç />
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Yeniden Kullanılabilir Bileşenler Oluşturma

React'ta bileşenler, yeniden kullanılabilir ve bağımsız parçalar olarak tasarlanabilir. Bu, projede tekrar kullanılabilirliği artırır ve geliştirme sürecini hızlandırır.

Örnek:

<script>
        function Buton(props) {
            return (
                <button onClick={props.onClick}>
                    {props.cocuk}
                </button>
            );
        }
        
        function App() {
            const handleClick = () => {
                alert('Butona tıkladınız!');
            };
        
            return (
                <div>
                    <Buton onClick={handleClick}>Tıkla</Buton>
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Bileşen Yaşam Döngüsü

React bileşenlerinin yaşam döngüsü, bileşenin oluşturulmasından, güncellenmesinden ve yok edilmesinden geçen süreçleri kapsar. Sınıf bileşenlerinde, yaşam döngüsü metodları kullanılarak bu süreçler yönetilebilir.

Örnek:

<script>
        class Sayaç extends React.Component {
            constructor(props) {
                super(props);
                this.state = { count: 0 };
            }
        
            componentDidMount() {
                console.log('Sayaç bileşeni eklendi.');
            }
        
            componentDidUpdate() {
                console.log('Sayaç bileşeni güncellendi.');
            }
        
            componentWillUnmount() {
                console.log('Sayaç bileşeni kaldırıldı.');
            }
        
            increment = () => {
                this.setState((prevState) => ({ count: prevState.count + 1 }));
            }
        
            render() {
                return (
                    <div>
                        <p>Butona {this.state.count} defa tıkladınız.</p>
                        <button onClick={this.increment}>Artır</button>
                    </div>
                );
            }
        }
        
        function App() {
            return (
                <div>
                    <Sayaç />
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Bileşen hiyerarşisi, üst bileşenler (parent components) ve alt bileşenler (child components) arasındaki ilişkileri tanımlar. Üst bileşenler, alt bileşenlere props ile veri aktarabilir ve alt bileşenlerin davranışını kontrol edebilir.

Bileşen Ağacı Yapısı

                        
Bileşen ağacı, bileşenlerin birbirine nasıl bağlı olduğunu ve nasıl iletişim kurduğunu gösterir. Bu yapı, uygulamanın mantıksal yapısını anlamak için kullanılır.

                        
Örnek:

                        
<script>
        function Anasayfa() {
            return (
                <div>
                    <h1>Anasayfa</h1>
                    <Menu />
                </div>
            );
        }
        
        function Menu() {
            return (
                <nav>

Bileşenlerin Stil Yönetimi

                        
Bileşen tabanlı mimaride, bileşenlerin stil yönetimi de önemlidir. Bileşenlerin stillerini yönetmek için çeşitli yöntemler kullanılabilir.

        
                        
CSS Dosyaları

                        
CSS dosyalarını bileşenlere dahil etmek için, CSS dosyasını bileşene import edebilirsiniz.

                        
Örnek:

                        
<script>
        import './Menu.css';
        
        function Menu() {
            return (
                <nav className="menu">
                    <ul>
                        <MenuItem isim="Ana Sayfa" />
                        <MenuItem isim="Hakkımızda" />
                        <MenuItem isim="İletişim" />
                    </ul>
                </nav>
            );
        }
        </script>
                        

        
                        
Inline Stiller

                        
Stil özelliklerini doğrudan bileşenlere uygulamak için inline stiller kullanılabilir.

                        
Örnek:

                        
<script>
        function Menu() {
            return (
                <nav style={{ backgroundColor: 'blue', color: 'white' }}>
                    <ul>
                        <MenuItem isim="Ana Sayfa" />
                        <MenuItem isim="Hakkımızda" />
                        <MenuItem isim="İletişim" />
                    </ul>
                </nav>
            );
        }
        </script>
                        

        
                        
CSS-in-JS Kütüphaneleri

                        
Styled-components veya Emotion gibi CSS-in-JS kütüphaneleri, stil bileşenleri oluşturarak stil yönetimini kolaylaştırır.

                        
Örnek (styled-components kullanarak):

                        
<script>
        import styled from 'styled-components';
        
        const Menu = styled.nav`
            background-color: blue;
            color: white;
        `;
        
        const MenuItem = styled.li`
            list-style: none;
        `;
        
        function App() {
            return (
                <Menu>
                    <ul>
                        <MenuItem>Ana Sayfa</MenuItem>
                        <MenuItem>Hakkımızda</MenuItem>
                        <MenuItem>İletişim</MenuItem>
                    </ul>
                </Menu>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
                        

        
                        
Bileşenlerin Test Edilmesi

                        
Bileşen tabanlı mimaride, bileşenlerin test edilmesi de önemli bir adımdır. Bileşenlerin doğru çalıştığından emin olmak için testler yazmak gerekir.

                        
Jest ve React Testing Library, React bileşenlerini test etmek için kullanılan popüler araçlardır.

        
                        
Jest ile Test Yapma

                        
Jest, Facebook tarafından geliştirilen ve React uygulamalarını test etmek için kullanılan bir test çerçevesidir.

                        
Örnek:

                        
<script>
        import { render, screen } from '@testing-library/react';
        import App from './App';
        
        test('renders Merhaba, Dünya! başlığı', () => {
            render(<App />);
            const baslikElement = screen.getByText(/Merhaba, Dünya!/i);
            expect(baslikElement).toBeInTheDocument();
        });
        </script>
                        

        
                        
React Testing Library

                        
React Testing Library, React bileşenlerini test etmek için kullanılan bir kütüphanedir. React Testing Library, bileşenlerin davranışını test etmeyi kolaylaştırır.

                        
Örnek:

                        
<script>
        import { render, fireEvent } from '@testing-library/react';
        import Sayaç from './Sayaç';
        
        test('sayaç butonuna tıklayınca artar', () => {
            const { getByText } = render(<Sayaç />);
            const buton = getByText('Artır');
            fireEvent.click(buton);
            const metin = getByText(/Butona 1 defa tıkladınız/i);
            expect(metin).toBeInTheDocument();
        });
        </script>
