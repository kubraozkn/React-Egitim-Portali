Tek Yönlü Veri Akışı (Unidirectional Data Flow)

Tek Yönlü Veri Akışı Nedir?

Tek yönlü veri akışı, bir uygulamanın veri akışının tek bir yönde ilerlediği bir mimari yaklaşımdır. Bu yaklaşım, veri akışını daha basit, tahmin edilebilir ve yönetilebilir hale getirir. Tek yönlü veri akışı, veri değişikliklerini ve bileşen güncellemelerini daha kolay izlemeyi sağlar.

Tek Yönlü Veri Akışının Avantajları

  • Tahmin Edilebilirlik: Veri akışı tek yönlü olduğunda, veri değişikliklerinin neden olduğu etkiler daha kolay izlenebilir ve tahmin edilebilir.
  • Kolay Bakım: Tek yönlü veri akışı, uygulamanın daha kolay bakımını sağlar ve hata ayıklama sürecini basitleştirir.
  • Modülerlik: Bileşenler ve veri akışı arasındaki net ayrım, uygulamanın modülerliğini artırır ve bileşenlerin bağımsız olarak geliştirilmesini kolaylaştırır.
  • Performans: Tek yönlü veri akışı, gereksiz yeniden render işlemlerini önleyerek uygulamanın performansını artırır.

React'ta Tek Yönlü Veri Akışı

React, tek yönlü veri akışını benimseyen bir kütüphanedir. React'ta veri, üst bileşenden alt bileşene doğru akar ve her bir bileşen kendi state'ini ve props'larını yönetir. Bu yapı, bileşenlerin daha izole ve yönetilebilir olmasını sağlar.

Örnek 1: Basit Bir React Bileşeni
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function Merhaba(props) {
            return <h1>Merhaba, {props.isim}!</h1>;
        }
        
        function App() {
            return <Merhaba isim="Dünya" />;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek 2: State ve Props Kullanımı
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => setCount(count + 1)}>Artır</button>
                </div>
            );
        }
        
        function App() {
            return <Sayaç />;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

State ve Props Yönetimi

React'ta, state ve props yönetimi, tek yönlü veri akışının temelini oluşturur. State, bileşenin kendi durumunu yönetir ve bileşen güncellemelerine neden olur. Props, üst bileşenden alt bileşene veri geçişini sağlar ve bileşenin dışarıdan nasıl davranacağını kontrol eder.

State Kullanımı
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => setCount(count + 1)}>Artır</button>
                </div>

        }

        </script>

State ve Props Arasındaki Fark

  • State: Bileşenin kendi durumunu yönetir ve bileşenin yeniden render edilmesine neden olur. State, bileşen içinde tanımlanır ve güncellenir.
  • Props: Üst bileşenden alt bileşene veri geçişini sağlar ve bileşenin dışarıdan nasıl davranacağını kontrol eder. Props, bileşene dışarıdan geçirilir ve bileşen içinde değiştirilemez.

Tek Yönlü Veri Akışının Uygulama Mimarisi

Tek yönlü veri akışı, uygulamanın veri akışını ve bileşenler arasındaki iletişimi düzenleyen bir mimari yapı sağlar. Bu yapı, uygulamanın daha tahmin edilebilir, yönetilebilir ve modüler olmasını sağlar.

Örnek Bir Uygulama Mimarisi:

<script>                                    
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function VeriGiriş({ onVeriGönder }) {
            const [input, setInput] = useState('');
        
            const gönder = () => {
                onVeriGönder(input);
                setInput('');
            };
        
            return (
                <div>
                    <input
                        type="text"
                        value={input}
                        onChange={(e) => setInput(e.target.value)}
                    />
                    <button onClick={gönder}>Gönder</button>
                </div>
            );
        }
        
        function VeriListe({ veri }) {
            return (
                <ul>
                    {veri.map((item, index) => (
                        <li key={index}>{item}</li>
                    ))}
                </ul>
            );
        }
        
        function App() {
            const [veri, setVeri] = useState([]);
        
            const veriEkle = (yeniVeri) => {
                setVeri([...veri, yeniVeri]);
            };
        
            return (
                <div>
                    <h1>Tek Yönlü Veri Akışı</h1>
                    <VeriGiriş onVeriGönder={veriEkle} />
                    <VeriListe veri={veri} />
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Tek Yönlü Veri Akışının Uygulama Örneği

Bu örnekte, kullanıcıdan alınan veriyi listeye ekleyerek tek yönlü veri akışının nasıl çalıştığını gösteriyoruz. Kullanıcıdan alınan veri önce üst bileşene (App) aktarılır, ardından üst bileşenden alt bileşenlere (VeriGiriş ve VeriListe) iletilir.

Özet

Tek yönlü veri akışı, uygulama geliştirmede veri akışının tahmin edilebilir, yönetilebilir ve modüler olmasını sağlayan güçlü bir yaklaşımdır. React, bu yaklaşımı benimseyerek bileşenlerin veri yönetimini kolaylaştırır ve uygulamaların performansını artırır.
