Yerel Bileşenler (Local Components)

Yerel Bileşen Nedir?

Yerel bileşenler, bir uygulamanın belirli bir bölümünde kullanılan ve yalnızca o bölümde işlev gören bileşenlerdir. Yerel bileşenler, global bileşenler gibi tüm uygulama genelinde kullanılmaz, aksine belirli bir konteks içinde kalırlar. Bu, bileşenlerin modüler ve izole olmasını sağlar.

Yerel Bileşenlerin Avantajları

  • Modülerlik: Yerel bileşenler, kodun daha modüler ve yönetilebilir olmasını sağlar.
  • Yeniden Kullanılabilirlik: Yerel bileşenler, farklı bölümlerde tekrar kullanılabilir, bu da kodun tekrarını azaltır.
  • İzole Edilmiş Fonksiyonellik: Yerel bileşenler, belirli bir konteks içinde izole edilmiş şekilde çalışır, bu da yan etkilerin minimize edilmesini sağlar.
  • Bakım Kolaylığı: Yerel bileşenler, bağımsız olduklarından bakımı ve güncellenmesi daha kolaydır.

React'ta Yerel Bileşenler Kullanımı

React'ta yerel bileşenler, bir bileşenin yalnızca belirli bir konteks içinde kullanılmasını sağlar. Bu, bileşenlerin daha izole ve yönetilebilir olmasını sağlar.

Örnek 1: Basit Bir Yerel Bileşen
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function Merhaba() {
            return <h1>Merhaba, Dünya!</h1>;
        }
        
        function App() {
            return <Merhaba />;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek 2: Yerel State ve Props Kullanımı
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => setCount(count + 1)}>Artır</button>
                </div>
            );
        }
        
        function App() {
            return <Sayaç />;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek 3: Yerel Bileşenler Arasında Veri Geçişi
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function Buton({ onClick }) {
            return <button onClick={onClick}>Butona Tıkla</button>;
        }
        
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            const artır = () => {
                setCount(count + 1);
            };
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <Buton onClick={artır} />
                </div>
            );
        }
        
        function App() {
            return <Sayaç />;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Yerel Bileşenlerin Kullanım Alanları

Yerel bileşenler, farklı kullanım alanlarında kullanılabilir. İşte bazı örnekler:

  • Form Elemanları: Form inputları, butonlar ve diğer form elemanları yerel bileşenler olarak tanımlanabilir ve yönetilebilir.
  • Liste Elemanları: Liste öğeleri, tablo satırları gibi tekrarlayan bileşenler yerel bileşenler olarak kullanılabilir.
  • Modallar ve Popup'lar: Modal pencereler ve popup'lar yerel bileşenler olarak tanımlanabilir ve belirli bir konteks içinde kullanılabilir.
  • Küçük UI Bileşenleri: İkonlar, etiketler ve küçük kullanıcı arayüzü bileşenleri yerel bileşenler olarak kullanılabilir.

Yerel Bileşenlerle Çalışırken Dikkat Edilmesi Gerekenler

  • Modülerlik: Yerel bileşenlerin modüler ve bağımsız olmasına dikkat edin. Bu, bileşenlerin tekrar kullanılabilirliğini artırır.
  • Veri Geçişi: Yerel bileşenler arasında veri geçişini props kullanarak yapın. Bu, veri akışının kontrolünü ve yönetimini kolaylaştırır.
  • İzole Edilmiş Fonksiyonellik: Yerel bileşenlerin izole edilmiş olmasına dikkat edin. Bu, bileşenlerin bağımsız çalışmasını ve yan etkilerin minimize edilmesini sağlar.
  • Performans: Yerel bileşenlerin performansını optimize edin. Gereksiz yeniden render etmeleri önlemek için useMemo ve useCallback gibi hook'ları kullanın.
