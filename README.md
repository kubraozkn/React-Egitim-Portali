React-Egitim-Portali

Proje Tanımı
React temel kavramlarını anlatan, yeni başlayanlar için geliştirilmiş öğretici bir web platformudur. Proje, karmaşık teknik bilgileri sadeleştirerek kullanıcıya sunmayı hedefler.

Proje Amacı
Modern web geliştirme süreçlerinde kritik öneme sahip olan bileşen tabanlı mimari, State yönetimi ve Virtual DOM gibi kavramların pratik üzerinden aktarılmasını sağlamak amacıyla geliştirilmiştir.

Kullanılan Teknolojiler
React.js: Dinamik kullanıcı arayüzü ve bileşen yönetimi.
JavaScript (ES6+): Mantıksal işlevsellik ve veri yönetimi.
HTML5 & CSS3: Sayfa yapısı ve responsive arayüz tasarımı.

Teknik Özellikler
Bileşen Tabanlı Mimari: Tekrar kullanılabilir ve modüler arayüz birimleri kurgulanmıştır.
Sanal DOM (Virtual DOM): Performans odaklı sayfa güncelleme yapısı kullanılmıştır.
İçerik Yönetimi: Konuların düzenli ilerlediği, kullanıcı dostu bir hiyerarşi oluşturulmuştur.

Teknik Kazanımlar
React ekosisteminde tek yönlü veri akışı (One-way data flow) prensibi uygulanmıştır.
Bileşenler arası veri aktarımı ve State yönetimi konularında uygulama deneyimi kazanılmıştır.
VS Code, Git ve GitHub gibi modern geliştirme araçları etkin bir şekilde kullanılmıştır.
