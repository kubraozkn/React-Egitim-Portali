React'a Hızlı Başlangıç

React Nedir?

React, kullanıcı arayüzleri oluşturmak için kullanılan, Facebook tarafından geliştirilmiş açık kaynaklı bir JavaScript kütüphanesidir. React, bileşen tabanlı mimarisi sayesinde tekrar kullanılabilir, dinamik ve hızlı kullanıcı arayüzleri oluşturmayı kolaylaştırır.

React Kurulumu

React projesi oluşturmak için Node.js ve npm (Node Package Manager) kullanılır. Node.js ve npm'i kurmak için Node.js Resmi Web Sitesi'ni ziyaret edebilirsiniz. React projesi oluşturmanın en hızlı ve kolay yolu, Create React App kullanmaktır.

Create React App kullanarak yeni bir React projesi oluşturmak için şu adımları izleyin:

<script>
        npx create-react-app my-app
        cd my-app
        npm start
        </script>

JSX (JavaScript XML)

JSX, JavaScript'te HTML benzeri sözdizimi kullanmanızı sağlayan bir JavaScript uzantısıdır. JSX, HTML ve JavaScript'in gücünü birleştirir ve bileşenlerin iç içe geçmesini kolaylaştırır.

Örnek:

<script>
        const element = <h1>Merhaba, Dünya!</h1>;
        const element = React.createElement('h1', null, 'Merhaba, Dünya!');
        </script>

React Bileşenleri

React bileşenleri, kullanıcı arayüzlerinin yapı taşlarıdır. Bir bileşen, bir JavaScript fonksiyonu veya sınıfı olarak tanımlanabilir ve kendi state ve props'larına sahip olabilir.

Fonksiyonel Bileşenler

Fonksiyonel bileşenler, bir JavaScript fonksiyonu olarak tanımlanan basit bileşenlerdir.

<script>
        function Merhaba(props) {
            return <h1>Merhaba, {props.isim}</h1>;
        }
        
        const App = () => (
            <div>
                <Merhaba isim="Dünya" />
            </div>
        );
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Sınıf Bileşenleri

Sınıf bileşenleri, bir JavaScript sınıfı olarak tanımlanan daha karmaşık bileşenlerdir.

<script>
        class Merhaba extends React.Component {
            render() {
                return <h1>Merhaba, {this.props.isim}</h1>;
            }
        }
        
        class App extends React.Component {
            render() {
                return (
                    <div>
                        <Merhaba isim="Dünya" />
                    </div>
                );
            }
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

State ve Props

State ve props, React bileşenlerinin veri yönetimi için kullandığı iki temel kavramdır.

State

State, bir bileşenin durumunu ifade eder ve bileşenin yeniden render edilmesine neden olur. useState hook'u ile state yönetimi yapılabilir.

<script>
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => setCount(count + 1)}>Artır</button>
                </div>
            );
        }
        
        const App = () => (
            <div>
                <Sayaç />
            </div>
        );
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Props

Props, bileşenler arasında veri taşımak için kullanılır. Props, üst bileşenden alt bileşene veri aktarımı sağlar.

<script>
        function Merhaba(props) {
            return <h1>Merhaba, {props.isim}</h1>;
        }
        
        const App = () => (
            <div>
                <Merhaba isim="Dünya" />
            </div>
        );
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React Hook'ları

React Hook'ları, React 16.8 sürümü ile tanıtılan ve sınıf bileşenleri kullanmadan state ve diğer React özelliklerini kullanmanıza olanak tanıyan fonksiyonlardır. İşte temel React Hook'ları:

useEffect Hook'u

useEffect, bileşenin yaşam döngüsü boyunca yan etkileri yönetmek için kullanılır. useEffect, bileşen ilk render edildiğinde ve her güncellendiğinde çalışır.

<script>
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            useEffect(() => {
                document.title = `Butona ${count} defa tıkladınız`;
            }, [count]);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => setCount(count + 1)}>Artır</button>
                </div>
            );
        }
        
        ReactDOM.render(<Sayaç />, document.getElementById('root'));
        </script>
useContext Hook'u

useContext, React Context API ile birlikte kullanılarak bileşenler arasında veri paylaşmayı sağlar. useContext, belirtilen context'in değerini döner.

<script>
        const TemaContext = createContext();
        
        function TemaButonu() {
            const { tema, temaDeğiştir } = useContext(TemaContext);
        
            return <button onClick={temaDeğiştir}>Tema: {tema}</button>;
        }
        
        function App() {
            const [tema, setTema] = useState('açık');
        
            const temaDeğiştir = () => {
                setTema((prevTema) => (prevTema === 'açık' ? 'karanlık' : 'açık'));
            };
        
            return (
                <TemaContext.Provider value={{ tema, temaDeğiştir }}>
                    <TemaButonu />
                </TemaContext.Provider>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React Router

React Router, React uygulamalarında sayfa yönlendirmesi yapmak için kullanılan popüler bir kütüphanedir. React Router ile uygulamanızda farklı sayfalar ve rotalar tanımlayabilirsiniz.

<script>
        import { BrowserRouter as Router, Route, Switch } from 'react-router-dom';
        
        const Anasayfa = () => <h1>Anasayfa</h1>;
        const Hakkimizda = () => <h1>Hakkımızda</h1>;
        const Iletisim = () => <h1>İletişim</h1>;
        
        function App() {
            return (
                <Router>
                    <Switch>
                        <Route exact path="/" component={Anasayfa} />
                        <Route path="/hakkimizda" component={Hakkimizda} />
                        <Route path="/iletisim" component={Iletisim} />
                    </Switch>
                </Router>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React Context API

React Context API, bir React uygulamasında bileşenler arasında global veri paylaşımını kolaylaştıran bir yapıdır. Context API, prop drilling olarak bilinen, üst bileşenlerden alt bileşenlere veri geçişini gereksiz hale getirir ve daha temiz bir veri geçişi sağlar.

Context Oluşturma ve Kullanma
<script>
        import React, { createContext, useState, useContext } from 'react';
        
        const TemaContext = createContext();
        
        function TemaButonu() {
            const { tema, temaDeğiştir } = useContext(TemaContext);
        
            return <button onClick={temaDeğiştir}>Tema: {tema}</button>;
        }
        
        function App() {
            const [tema, setTema] = useState('açık');
        
            const temaDeğiştir = () => {
                setTema((prevTema) => (prevTema === 'açık' ? 'karanlık' : 'açık'));
            };
        
            return (
                <TemaContext.Provider value={{ tema, temaDeğiştir }}>
                    <TemaButonu />
                </TemaContext.Provider>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

State Yönetimi

React uygulamalarında state yönetimi için popüler kütüphaneler arasında Redux ve MobX bulunur. Redux, merkezi bir state yönetimi sağlar ve uygulamanın tahmin edilebilir ve yönetilebilir olmasını sağlar.

Redux Kullanımı
<script>
        import { createStore } from 'redux';
        import { Provider, useDispatch, useSelector } from 'react-redux';
        
        const initialState = { count: 0 };
        
        const reducer = (state = initialState, action) => {
            switch (action.type) {
                case 'INCREMENT':
                    return { ...state, count: state.count + 1 };
                default:
                    return state;
            }
        };
        
        const store = createStore(reducer);
        
        function Sayaç() {
            const count = useSelector((state) => state.count);
            const dispatch = useDispatch();
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => dispatch({ type: 'INCREMENT' })}>Artır</button>
                </div>
            );
        }
        
        function App() {
            return (
                <Provider store={store}>
                    <Sayaç />
                </Provider>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React ile Form Yönetimi

React uygulamalarında form yönetimi ve doğrulaması yapmak için popüler kütüphaneler arasında Formik ve React Hook Form bulunur.

Formik Kullanımı
<script>
        import { Formik, Form, Field, ErrorMessage } from 'formik';
        
        function KayıtFormu() {
            return (
                <Formik
                    initialValues={{ isim: '', email: '' }}
                    validate={values => {
                        const errors = {};
                        if (!values.isim) {
                            errors.isim = 'İsim gerekli';
                        }
                        if (!values.email) {
                            errors.email = 'Email gerekli';
                        } else if (
                            !/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i.test(values.email)
                        ) {
                            errors.email = 'Geçersiz email adresi';
                        }
                        return errors;
                    }}
                    onSubmit={(values, { setSubmitting }) => {
                        setTimeout(() => {
                            alert(JSON.stringify(values, null, 2));
                            setSubmitting(false);
                        }, 400);
                    }}
                >
                    {({ isSubmitting }) => (
                        <Form>
                            <div>
                                <Field type="text" name="isim" />
                                <ErrorMessage name="isim" component="div" />
                            </div>
                            <div>
                                <Field type="email" name="email" />
                                <ErrorMessage name="email" component="div" />
                            </div>
                            <button type="submit" disabled={isSubmitting}>
                                Gönder
                            </button>
                        </Form>
                    )}
                </Formik>
            );
        }
        
        ReactDOM.render(<KayıtFormu />, document.getElementById('root'));
        </script>

API İstemcileri

React uygulamalarında API talepleri yapmak için popüler kütüphaneler arasında Axios ve Fetch bulunur.

Axios Kullanımı
<script>
        import axios from 'axios';
        
        function VeriGetir() {
            const [veri, setVeri] = useState([]);
        
            useEffect(() => {
                axios.get('https://api.example.com/data')
                    .then(response => setVeri(response.data))
                    .catch(error => console.error('Veri çekme hatası:', error));
            }, []);
        
            return (
                <div>
                    <h1>API'den Gelen Veriler</h1>
                    <ul>
                        {veri.map((item, index) => (
                            <li key={index}>{item}</li>
                        ))}
                    </ul>
                </div>
            );
        }
        
        ReactDOM.render(<VeriGetir />, document.getElementById('root'));
        </script>
Fetch Kullanımı
<script>
        function VeriGetir() {
            const [veri, setVeri] = useState([]);
        
            useEffect(() => {
                fetch('https://api.example.com/data')
                    .then(response => response.json())
                    .then(data => setVeri(data))
                    .catch(error => console.error('Veri çekme hatası:', error));
            }, []);
        
            return (
                <div>
                    <h1>API'den Gelen Veriler</h1>
                    <ul>
                        {veri.map((item, index) => (
                            <li key={index}>{item}</li>
                        ))}
                    </ul>
                </div>
            );
        }
        
        ReactDOM.render(<VeriGetir />, document.getElementById('root'));
        </script>

Performans Optimizasyonu

React uygulamalarında performans optimizasyonu yapmak için çeşitli teknikler ve araçlar kullanılabilir. İşte bazıları:

  • shouldComponentUpdate: Sınıf bileşenlerinde, shouldComponentUpdate metodunu kullanarak bileşenin yeniden render edilip edilmeyeceğini kontrol edebilirsiniz.
  • React.memo: Fonksiyonel bileşenlerde, React.memo ile bileşenin sadece props değiştiğinde yeniden render edilmesini sağlayabilirsiniz.
  • useMemo ve useCallback: useMemo ve useCallback hook'ları ile hesaplamalı değerlerin ve fonksiyonların yalnızca bağımlılıkları değiştiğinde yeniden oluşturulmasını sağlayabilirsiniz.
  • Lazy Loading: React.lazy ve Suspense kullanarak bileşenlerin ve modüllerin sadece ihtiyaç duyulduğunda yüklenmesini sağlayabilirsiniz.
Örnek: shouldComponentUpdate Kullanımı
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        class Merhaba extends React.Component {
            shouldComponentUpdate(nextProps) {
                return nextProps.isim !== this.props.isim;
            }
        
            render() {
                return <h1>Merhaba, {this.props.isim}!</h1>;
            }
        }
        
        class App extends React.Component {
            constructor(props) {
                super(props);
                this.state = { isim: 'Dünya' };
            }
        
            render() {
                return <Merhaba isim={this.state.isim} />;
            }
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek: React.memo Kullanımı
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        const Merhaba = React.memo(function (props) {
            return <h1>Merhaba, {props.isim}!</h1>;
        });
        
        class App extends React.Component {
            constructor(props) {
                super(props);
                this.state = { isim: 'Dünya' };
            }
        
            render() {
                return <Merhaba isim={this.state.isim} />;
            }
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek: useMemo Kullanımı
<script>
        import React, { useMemo } from 'react';
        import ReactDOM from 'react-dom';
        
        function Hesapla({ numara }) {
            const hesaplananDeger = useMemo(() => {
                return numara * 2;
            }, [numara]);
        
            return <div>Sonuç: {hesaplananDeger}</div>;
        }
        
        function App() {
            const [numara, setNumara] = useState(0);
        
            return (
                <div>
                    <Hesapla numara={numara} />
                    <button onClick={() => setNumara(numara + 1)}>Artır</button>
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek: useCallback Kullanımı
<script>
        import React, { useState, useCallback } from 'react';
        import ReactDOM from 'react-dom';
        
        function Buton({ onClick }) {
            return <button onClick={onClick}>Tıkla</button>;
        }
        
        function App() {
            const [count, setCount] = useState(0);
        
            const artır = useCallback(() => {
                setCount((prevCount) => prevCount + 1);
            }, []);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <Buton onClick={artır} />
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek: Lazy Loading Kullanımı
<script>
        import React, { lazy, Suspense } from 'react';
        import ReactDOM from 'react-dom';
        
        const Merhaba = lazy(() => import('./Merhaba'));
        
        function App() {
            return (
                <Suspense fallback=<div>Yükleniyor...</div>>
                    <Merhaba />
                </Suspense>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

                        <Route path="/hakkimizda" component={Hakkimizda} />
                        <Route path="/iletisim" component={Iletisim} />
                    </Switch>
                </Router>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React Context API

React Context API, bir React uygulamasında bileşenler arasında global veri paylaşımını kolaylaştıran bir yapıdır. Context API, prop drilling olarak bilinen, üst bileşenlerden alt bileşenlere veri geçişini gereksiz hale getirir ve daha temiz bir veri geçişi sağlar.

Context Oluşturma ve Kullanma
<script>
        import React, { createContext, useState, useContext } from 'react';
        
        const TemaContext = createContext();
        
        function TemaButonu() {
            const { tema, temaDeğiştir } = useContext(TemaContext);
        
            return <button onClick={temaDeğiştir}>Tema: {tema}</button>;
        }
        
        function App() {
            const [tema, setTema] = useState('açık');
        
            const temaDeğiştir = () => {
                setTema((prevTema) => (prevTema === 'açık' ? 'karanlık' : 'açık'));
            };
        
            return (
                <TemaContext.Provider value={{ tema, temaDeğiştir }}>
                    <TemaButonu />
                </TemaContext.Provider>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

State Yönetimi

React uygulamalarında state yönetimi için popüler kütüphaneler arasında Redux ve MobX bulunur. Redux, merkezi bir state yönetimi sağlar ve uygulamanın tahmin edilebilir ve yönetilebilir olmasını sağlar.

Redux Kullanımı
<script>
        import { createStore } from 'redux';
        import { Provider, useDispatch, useSelector } from 'react-redux';
        
        const initialState = { count: 0 };
        
        const reducer = (state = initialState, action) => {
            switch (action.type) {
                case 'INCREMENT':
                    return { ...state, count: state.count + 1 };
                default:
                    return state;
            }
        };
        
        const store = createStore(reducer);
        
        function Sayaç() {
            const count = useSelector((state) => state.count);
            const dispatch = useDispatch();
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => dispatch({ type: 'INCREMENT' })}>Artır</button>
                </div>
            );
        }
        
        function App() {
            return (
                <Provider store={store}>
                    <Sayaç />
                </Provider>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React ile Form Yönetimi

React uygulamalarında form yönetimi ve doğrulaması yapmak için popüler kütüphaneler arasında Formik ve React Hook Form bulunur.

Formik Kullanımı
<script>
        import { Formik, Form, Field, ErrorMessage } from 'formik';
        
        function KayıtFormu() {
            return (
                <Formik
                    initialValues={{ isim: '', email: '' }}
                    validate={values => {
                        const errors = {};
                        if (!values.isim) {
                            errors.isim = 'İsim gerekli';
                        }
                        if (!values.email) {
                            errors.email = 'Email gerekli';
                        } else if (
                            !/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i.test(values.email)
                        ) {
                            errors.email = 'Geçersiz email adresi';
                        }
                        return errors;
                    }}
                    onSubmit={(values, { setSubmitting }) => {
                        setTimeout(() => {
                            alert(JSON.stringify(values, null, 2));
                            setSubmitting(false);
                        }, 400);
                    }}
                >
                    {({ isSubmitting }) => (
                        <Form>
                            <div>
                                <Field type="text" name="isim" />
                                <ErrorMessage name="isim" component="div" />
                            </div>
                            <div>
                                <Field type="email" name="email" />
                                <ErrorMessage name="email" component="div" />
                            </div>
                            <button type="submit" disabled={isSubmitting}>
                                Gönder
                            </button>
                        </Form>
                    )}
                </Formik>
            );
        }
        
        ReactDOM.render(<KayıtFormu />, document.getElementById('root'));
        </script>

Performans Optimizasyonu

React uygulamalarında performans optimizasyonu yapmak için çeşitli teknikler ve araçlar kullanılabilir. İşte bazıları:

  • shouldComponentUpdate: Sınıf bileşenlerinde, shouldComponentUpdate metodunu kullanarak bileşenin yeniden render edilip edilmeyeceğini kontrol edebilirsiniz.
  • React.memo: Fonksiyonel bileşenlerde, React.memo ile bileşenin sadece props değiştiğinde yeniden render edilmesini sağlayabilirsiniz.
  • useMemo ve useCallback: useMemo ve useCallback hook'ları ile hesaplamalı değerlerin ve fonksiyonların yalnızca bağımlılıkları değiştiğinde yeniden oluşturulmasını sağlayabilirsiniz.
  • Lazy Loading: React.lazy ve Suspense kullanarak bileşenlerin ve modüllerin sadece ihtiyaç duyulduğunda yüklenmesini sağlayabilirsiniz.
Örnek: shouldComponentUpdate Kullanımı
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        class Merhaba extends React.Component {
            shouldComponentUpdate(nextProps) {
                return nextProps.isim !== this.props.isim;
            }
        
            render() {
                return <h1>Merhaba, {this.props.isim}!</h1>;
            }
        }
        
        class App extends React.Component {
            constructor(props) {
                super(props);
                this.state = { isim: 'Dünya' };
            }
        
            render() {
                return <Merhaba isim={this.state.isim} />;
            }
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Örnek: useMemo Kullanımı
<script>
        import React, { useMemo } from 'react';
        import ReactDOM from 'react-dom';
        
        function Hesapla({ numara }) {
            const hesaplananDeger = useMemo(() => {
                return numara * 2;
            }, [numara]);
        
            return <div>Sonuç: {hesaplananDeger}</div>;
        }
        
        function App() {
            const [numara, setNumara] = useState(0);
        
            return (
                <div>
                    <Hesapla numara={numara} />

            );
        }

        </script>
Örnek: useCallback Kullanımı
<script>
        import React, { useState, useCallback } from 'react';
        import ReactDOM from 'react-dom';
        
        function Buton({ onClick }) {
            return <button onClick={onClick}>Tıkla</button>;
        }
        
        function App() {
            const [count, setCount] = useState(0);
        
            const artır = useCallback(() => {
                setCount((prevCount) => prevCount + 1);
            }, []);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <Buton onClick={artır} />
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek: Lazy Loading Kullanımı
<script>

        import ReactDOM from 'react-dom';
        
        const Merhaba = lazy(() => import('./Merhaba'));

            return (
                <Suspense fallback=<div>Yükleniyor...</div>>
                    <Merhaba />
                </Suspense>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
