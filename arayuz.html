Kullanıcı Arayüzü (UI) Tanımlama ve Örnekler

Kullanıcı Arayüzü (UI) Nedir?

Kullanıcı Arayüzü, kullanıcıların bir sistem, uygulama veya web sitesi ile etkileşimde bulunduğu arayüzdür. UI, görsel tasarım, interaktif öğeler ve kullanıcı deneyimini iyileştirmek için kullanılan diğer elemanları içerir.

UI Elemanları:

  • Butonlar: Kullanıcıların eylem gerçekleştirmesini sağlar.
  • Formlar: Kullanıcıların bilgi girmesini ve göndermesini sağlar.
  • Navigasyon Menüsü: Kullanıcıların site içinde gezinmesini sağlar.

UI Tasarım İlkeleri:

  • Basitlik: Arayüzü mümkün olduğunca basit ve anlaşılır tutmak.
  • Tutarlılık: Tasarım unsurlarında tutarlılığı sağlamak (renkler, yazı tipleri, buton stilleri vb.).
  • Geri Bildirim: Kullanıcılara yaptıkları eylemler hakkında geri bildirim sağlamak (örneğin, bir butona basıldığında renk değişimi).
  • Erişilebilirlik: Herkesin kullanabileceği şekilde tasarım yapmak (erişilebilir renkler, okunabilir metinler vb.).
  • Estetik: Görsel olarak hoş ve kullanıcı dostu bir tasarım oluşturmak.

React ile Kullanıcı Arayüzü Tasarımı

React, bileşen tabanlı mimarisi sayesinde kullanıcı arayüzü tasarımını kolaylaştırır. React bileşenleri, tekrar kullanılabilir ve modüler bir yapıya sahiptir, bu da arayüz tasarımını daha yönetilebilir hale getirir.

Örnek 1: Basit Bir React Bileşeni ile UI Tasarımı
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function Merhaba() {
            return <h1>Merhaba, Dünya!</h1>;
        }
        
        ReactDOM.render(<Merhaba />, document.getElementById('root'));
        </script>
Örnek 2: Form Elemanları ile UI Tasarımı
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function KayıtFormu() {
            const [isim, setIsim] = useState('');
            const [email, setEmail] = useState('');
        
            const handleSubmit = (e) => {
                e.preventDefault();
                alert(`İsim: ${isim}, Email: ${email}`);
            };
        
            return (
                <form onSubmit={handleSubmit}>
                    <div>
                        <label>İsim:</label>
                        <input type="text" value={isim} onChange={(e) => setIsim(e.target.value)} />
                    </div>
                    <div>
                        <label>Email:</label>
                        <input type="email" value={email} onChange={(e) => setEmail(e.target.value)} />
                    </div>
                    <button type="submit">Gönder</button>
                </form>
            );
        }
        
        ReactDOM.render(<KayıtFormu />, document.getElementById('root'));
        </script>

Örnek 4: Modal Pencere ile UI Tasarımı
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function Modal({ showModal, closeModal }) {
            if (!showModal) return null;
        
            return (
                <div className="modal">
                    <div className="modal-content">
                        <span className="close" onClick={closeModal}>×</span>
                        <p>Bu bir modal penceredir.</p>
                    </div>
                </div>
            );
        }
        
        function App() {
            const [showModal, setShowModal] = useState(false);
        
            const openModal = () => setShowModal(true);
            const closeModal = () => setShowModal(false);
        
            return (
                <div>
                    <button onClick={openModal}>Modal Aç</button>
                    <Modal showModal={showModal} closeModal={closeModal} />
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Örnek 5: Tablo ile UI Tasarımı
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function VeriTablosu({ veriler }) {
            return (
                <table>
                    <thead>
                        <tr>
                            <th>ID</th>
                            <th>İsim</th>
                            <th>Email</th>
                        </tr>
                    </thead>
                    <tbody>
                        {veriler.map((veri) => (
                            <tr key={veri.id}>
                                <td>{veri.id}</td>
                                <td>{veri.isim}</td>
                                <td>{veri.email}</td>
                            </tr>
                        ))}
                    </tbody>
                </table>
            );
        }
        
        function App() {
            const veriler = [
                { id: 1, isim: 'Ali', email: 'ali@example.com' },
                { id: 2, isim: 'Ayşe', email: 'ayse@example.com' },
                { id: 3, isim: 'Fatma', email: 'fatma@example.com' },
            ];
        
            return <VeriTablosu veriler={veriler} />;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React ile UI Bileşen Kütüphaneleri

React, birçok popüler UI bileşen kütüphanesi ile birlikte kullanılabilir. İşte bazı popüler UI kütüphaneleri:

  • Material-UI: Google'ın Material Design yönergelerine göre tasarlanmış bir React UI kütüphanesidir.
  • Ant Design: Kurumsal düzeyde uygulamalar için tasarlanmış zengin özelliklere sahip bir React UI kütüphanesidir.
  • Semantic UI React: Semantic UI tabanlı bir React UI kütüphanesidir.
  • Chakra UI: Basitlik ve erişilebilirlik üzerine odaklanan bir React UI kütüphanesidir.
Material-UI Kullanımı

Material-UI, Google'ın Material Design yönergelerine göre tasarlanmış bir React UI kütüphanesidir. İşte basit bir buton bileşeni örneği:

<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        import Button from '@material-ui/core/Button';
        
        function App() {
            return <Button variant="contained" color="primary">Material-UI Buton</Button>;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Ant Design Kullanımı

Ant Design, kurumsal düzeyde uygulamalar için tasarlanmış zengin özelliklere sahip bir React UI kütüphanesidir. İşte basit bir buton bileşeni örneği:

<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        import { Button } from 'antd';
        
        function App() {
            return <Button type="primary">Ant Design Buton</Button>;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Semantic UI React Kullanımı

Semantic UI React, Semantic UI tabanlı bir React UI kütüphanesidir. İşte basit bir buton bileşeni örneği:

<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        import { Button } from 'semantic-ui-react';
        
        function App() {
            return <Button primary>Semantic UI Buton</Button>;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Chakra UI Kullanımı

Chakra UI, basitlik ve erişilebilirlik üzerine odaklanan bir React UI kütüphanesidir. İşte basit bir buton bileşeni örneği:

<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        import { Button } from '@chakra-ui/react';
        
        function App() {
            return <Button colorScheme="blue">Chakra UI Buton</Button>;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

Erişilebilirlik (Accessibility)

Kullanıcı arayüzü tasarımında erişilebilirlik, tüm kullanıcıların uygulamanızı kullanabilmesini sağlamaktır. Erişilebilirlik standartlarına uymak için şu adımları takip edebilirsiniz:

  • Alt Metin Kullanımı: Görseller için alt metin kullanarak ekran okuyucularının görüntüleri tanımlamasını sağlayın.
  • Kontrast Oranı: Metin ve arka plan arasındaki kontrastı artırarak metnin okunabilirliğini sağlayın.
  • Odak Görünürlüğü: Klavye ile gezinirken odaklanan öğelerin görünürlüğünü artırın.
  • Araç İpuçları: Form elemanları ve butonlar için araç ipuçları kullanarak kullanıcıların işlevleri anlamalarına yardımcı olun.
  • WAI-ARIA Özellikleri: WAI-ARIA özelliklerini kullanarak erişilebilirliği artırın.
Alt Metin Kullanımı Örneği
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function Görsel() {
            return <img src="image.jpg" alt="Açıklayıcı Alt Metin" />;
        }
        
        ReactDOM.render(<Görsel />, document.getElementById('root'));
        </script>
Kontrast Oranı Örneği
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function KontrastMetin() {
            const stil = {
                backgroundColor: 'black',
                color: 'white',
                padding: '10px'
            };
        
            return <div style={stil}>Bu metin yüksek kontrastlıdır.</div>;
        }
        
        ReactDOM.render(<KontrastMetin />, document.getElementById('root'));
        </script>
Odak Görünürlüğü Örneği
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function OdakButonu() {
            const stil = {
                ':focus': {
                    outline: '3px solid blue'
                }
            };
        
            return <button style={stil}>Odaklanan Buton</button>;
        }
        
        ReactDOM.render(<OdakButonu />, document.getElementById('root'));
        </script>
Araç İpuçları Örneği
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function AraçİpucuButonu() {
            return <button title="Bu bir araç ipucudur">Araç İpucu Butonu</button>;
        }
        
        ReactDOM.render(<AraçİpucuButonu />, document.getElementById('root'));
        </script>
WAI-ARIA Özellikleri Örneği
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function WAIARIAButonu() {
            return <button aria-label="Bu bir WAI-ARIA butonudur">WAI-ARIA Butonu</button>;
        }
        
        ReactDOM.render(<WAIARIAButonu />, document.getElementById('root'));
        </script>
