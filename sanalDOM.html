Sanal DOM (Virtual DOM)

Sanal DOM Nedir?

Sanal DOM (Virtual DOM), modern JavaScript kütüphaneleri ve çerçeveleri tarafından kullanılan, daha hızlı ve verimli bir şekilde DOM manipülasyonu sağlayan bir teknikdir. Sanal DOM, DOM'un hafif ve hafızada tutulan bir kopyasıdır ve gerçek DOM üzerinde yapılan değişikliklerin minimum gecikme ve maksimum performans ile uygulanmasını sağlar.

Sanal DOM'un Avantajları

  • Performans Artışı: Sanal DOM, yalnızca gerekli değişiklikleri gerçek DOM'a uygular, bu da performansı artırır ve gereksiz yeniden render etmelerden kaçınılmasını sağlar.
  • Verimlilik: Sanal DOM, hafızada tutulduğundan, DOM manipülasyonları daha verimli bir şekilde gerçekleştirilir ve tarayıcıda daha hızlı güncellemeler yapılır.
  • Karmaşıklığın Azaltılması: Sanal DOM, geliştiricilere daha basit ve temiz bir API sunar, bu da karmaşık DOM manipülasyonlarının yönetimini kolaylaştırır.
  • Geriye Dönük Uyum: Sanal DOM, farklı tarayıcılar ve tarayıcı sürümleri arasında uyumluluğu sağlar ve eski tarayıcılarda bile düzgün çalışır.

Sanal DOM Nasıl Çalışır?

Sanal DOM, DOM manipülasyonlarının daha hızlı ve verimli bir şekilde yapılmasını sağlar. Sanal DOM, şu adımlarla çalışır:

  1. Sanal DOM Oluşturma: React bileşenleri, sanal DOM'un hafızada tutulan bir kopyasını oluşturur.
  2. Değişikliklerin Belirlenmesi: Bileşenlerin state veya props'ları değiştiğinde, sanal DOM yeni bir sanal DOM ağacı oluşturur ve önceki sanal DOM ağacı ile karşılaştırılır. Bu işlem, "diffing" olarak adlandırılır.
  3. Gerekli Değişikliklerin Belirlenmesi: Diffing işlemi sonucunda, yalnızca gerekli değişiklikler belirlenir ve bu değişiklikler gerçek DOM'a uygulanır. Bu işlem, "patching" olarak adlandırılır.
  4. Gerçek DOM'un Güncellenmesi: Patching işlemi ile belirlenen değişiklikler gerçek DOM'a uygulanır ve kullanıcı arayüzü güncellenir.

React'ta Sanal DOM Kullanımı

React, sanal DOM'u kullanarak bileşenlerin daha hızlı ve verimli bir şekilde güncellenmesini sağlar. İşte React'ta sanal DOM kullanımını gösteren örnekler:

Örnek 1: Basit Bir React Bileşeni
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function Merhaba() {
            return <h1>Merhaba, Dünya!</h1>;
        }
        
        ReactDOM.render(<Merhaba />, document.getElementById('root'));
        </script>
Örnek 2: State ve Sanal DOM Kullanımı
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        
        function Sayaç() {
            const [count, setCount] = useState(0);
        
            return (
                <div>
                    <p>Butona {count} defa tıkladınız.</p>
                    <button onClick={() => setCount(count + 1)}>Artır</button>
                </div>
            );
        }
        
        ReactDOM.render(<Sayaç />, document.getElementById('root'));
        </script>
Örnek 3: Props ve Sanal DOM Kullanımı
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        function Merhaba(props) {
            return <h1>Merhaba, {props.isim}!</h1>;
        }
        
        function App() {
            return <Merhaba isim="Dünya" />;
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

React'in Diffing Algoritması

React'in diffing algoritması, sanal DOM'daki değişiklikleri belirlemek için kullanılır. Bu algoritma, iki sanal DOM ağacını karşılaştırarak, yalnızca gerekli değişiklikleri belirler ve gerçek DOM'a uygular. Diffing algoritmasının temel prensipleri şunlardır:

  • Element Türü: Eğer iki elemanın türü aynıysa, React sadece elementin özelliklerini günceller. Eğer farklıysa, eski elemanı kaldırır ve yeni elemanı ekler.
  • Key Özelliği: Eğer listelerdeki elemanlar aynı key değerine sahipse, React bu elemanları karşılaştırır ve günceller. Eğer farklı key değerlerine sahipse, React eski elemanları kaldırır ve yeni elemanları ekler.

Diffing algoritması, performansı artırmak ve gereksiz DOM manipülasyonlarını önlemek için optimize edilmiştir.

React Fiber

React Fiber, React'in yeni uzatma ve render motorudur. Fiber, sanal DOM'daki değişikliklerin daha verimli bir şekilde yönetilmesini sağlar ve kullanıcı arayüzü güncellemelerini daha hızlı hale getirir. Fiber, özellikle büyük ve karmaşık uygulamalarda performans iyileştirmeleri sağlar.

React Profiler ile Performans Analizi

React Profiler, bileşenlerin performansını analiz etmek ve optimize etmek için kullanılan bir araçtır. Profiler, bileşenlerin render sürelerini, state ve props güncellemelerini ve bileşenlerin ne sıklıkla render edildiğini gösterir. React Profiler, performans sorunlarını tespit etmek ve uygulamanın performansını artırmak için kullanılır.

React Profiler'ı tarayıcınıza eklemek için React Profiler Resmi Sayfası'nı ziyaret edebilirsiniz.

React ile Animasyonlar

React uygulamalarında animasyonlar eklemek için, CSS animasyonları, React Transition Group veya React Spring gibi kütüphaneler kullanılabilir. Bu kütüphaneler, bileşenlerin giriş, çıkış ve geçiş animasyonlarını kolayca eklemeyi sağlar.

React Transition Group Kullanımı
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        import { CSSTransition, TransitionGroup } from 'react-transition-group';
        import './animasyon.css';
        
        function Liste({ öğeler }) {
            return (
                <TransitionGroup>
                    {öğeler.map(öğe => (
                        <CSSTransition key={öğe} timeout={500} classNames="fade">
                            <div>{öğe}</div>
                        </CSSTransition>
                    ))}
                </TransitionGroup>
            );
        }
        
        const öğeler = ['Öğe 1', 'Öğe 2', 'Öğe 3'];
        
        ReactDOM.render(<Liste öğeler={öğeler} />, document.getElementById('root'));
        </script>
                        
<script>
        import React, { useState } from 'react';
        
<script>
        import React, { useState } from 'react';
        import ReactDOM from 'react-dom';
        import { CSSTransition, TransitionGroup } from 'react-transition-group';
        import './animasyon.css';
        
        function App() {
            const [items, setItems] = useState(['Öğe 1', 'Öğe 2', 'Öğe 3']);
            
            const addItem = () => {
                const newItem = `Öğe ${items.length + 1}`;
                setItems([...items, newItem]);
            };
            
            return (
                <div>
                    <button onClick={addItem}>Öğe Ekle</button>
                    <TransitionGroup>
                        {items.map((item, index) => (
                            <CSSTransition key={index} timeout={500} classNames="fade">
                                <div>{item}</div>
                            </CSSTransition>
                        ))}
                    </TransitionGroup>
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
        

        
        
React ile Performans Optimizasyonu

        
React uygulamalarında performans optimizasyonu yapmak için çeşitli teknikler ve araçlar kullanılabilir. İşte bazıları:

        
    
            
  • shouldComponentUpdate: Sınıf bileşenlerinde, shouldComponentUpdate metodunu kullanarak bileşenin yeniden render edilip edilmeyeceğini kontrol edebilirsiniz.
    • 
            
  • React.memo: Fonksiyonel bileşenlerde, React.memo ile bileşenin sadece props değiştiğinde yeniden render edilmesini sağlayabilirsiniz.
    • 
            
  • useMemo ve useCallback: useMemo ve useCallback hook'ları ile hesaplamalı değerlerin ve fonksiyonların yalnızca bağımlılıkları değiştiğinde yeniden oluşturulmasını sağlayabilirsiniz.
    • 
            
  • Lazy Loading: React.lazy ve Suspense kullanarak bileşenlerin ve modüllerin sadece ihtiyaç duyulduğunda yüklenmesini sağlayabilirsiniz.
    • 
        

        
        
Örnek: shouldComponentUpdate Kullanımı

        
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        class Merhaba extends React.Component {
            shouldComponentUpdate(nextProps) {
                return nextProps.isim !== this.props.isim;
            }
        
            render() {
                return <h1>Merhaba, {this.props.isim}!</h1>;
            }
        }
        
        class App extends React.Component {
            constructor(props) {
                super(props);
                this.state = { isim: 'Dünya' };
            }
        
            render() {
                return <Merhaba isim={this.state.isim} />;
            }
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
        

        
        
Örnek: React.memo Kullanımı

        
<script>
        import React from 'react';
        import ReactDOM from 'react-dom';
        
        const Merhaba = React.memo(function (props) {
            return <h1>Merhaba, {props.isim}!</h1>;
        });
        
        class App extends React.Component {
            constructor(props) {
                super(props);
                this.state = { isim: 'Dünya' };
            }
        
            render() {
                return <Merhaba isim={this.state.isim} />;
            }
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
        

        
        
Örnek: useMemo Kullanımı

        
<script>
        import React, { useMemo } from 'react';
        import ReactDOM from 'react-dom';
        
        function Hesapla({ numara }) {
            const hesaplananDeger = useMemo(() => {
                return numara * 2;
            }, [numara]);
        
            return <div>Sonuç: {hesaplananDeger}</div>;
        }
        
        function App() {
            const [numara, setNumara] = React.useState(0);
        
            return (
                <div>
                    <Hesapla numara={numara} />
                    <button onClick={() => setNumara(numara + 1)}>Artır</button>
                </div>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
        

        
        
Örnek: Lazy Loading Kullanımı

        
<script>
        import React, { lazy, Suspense } from 'react';
        import ReactDOM from 'react-dom';
        
        const Merhaba = lazy(() => import('./Merhaba'));
        
        function App() {
            return (
                <Suspense fallback="<div>Yükleniyor...</div>">
                    <Merhaba />
                </Suspense>
            );
        }
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
