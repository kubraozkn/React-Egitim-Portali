React'ta Kaçış Yolları (Escape Hatches)

React Nedir?

React, kullanıcı arayüzleri oluşturmak için kullanılan, Facebook tarafından geliştirilmiş açık kaynaklı bir JavaScript kütüphanesidir. React, bileşen tabanlı mimarisi sayesinde tekrar kullanılabilir, dinamik ve hızlı kullanıcı arayüzleri oluşturmayı kolaylaştırır.

Kaçış Yolları Nedir?

Kaçış yolları (escape hatches), React bileşenlerinde ve uygulamalarında daha fazla esneklik ve kontrol sağlamak için kullanılan gelişmiş tekniklerdir. Bu teknikler, normalde React'ın sunduğu yapıları ve kısıtlamaları aşarak özel çözümler üretmenizi sağlar.

Kaçış Yolları İçin Temel Teknikler

Refs (Referanslar)

Refs, bileşenlerin DOM elemanlarına doğrudan erişim sağlamak için kullanılır. Bu, özellikle odak yönetimi, metin seçimi veya üçüncü taraf kütüphanelerle entegrasyon gibi durumlar için kullanışlıdır.

Örnek:

<script>
        const inputRef = React.createRef();
        
        const focusInput = () => {
            inputRef.current.focus();
        };
        
        return (
            <div>
                <input ref={inputRef} type="text" />
                <button onClick={focusInput}>Odağı Ayarla</button>
            </div>
        );
        </script>
React Portals

React Portals, bileşenlerin DOM hiyerarşisinin dışında render edilmesini sağlar. Bu, modallar, açılır menüler ve araç ipuçları gibi bileşenlerin uygulamanın köküne yakın bir yerde render edilmesi gerektiğinde kullanılır.

Örnek:

<script>
        const modalRoot = document.getElementById('modal-root');
        
        class Modal extends React.Component {
            constructor(props) {
                super(props);
                this.el = document.createElement('div');
            }
        
            componentDidMount() {
                modalRoot.appendChild(this.el);
            }
        
            componentWillUnmount() {
                modalRoot.removeChild(this.el);
            }
        
            render() {
                return ReactDOM.createPortal(
                    this.props.children,
                    this.el
                );
            }
        }
        
        const App = () => (
            <div>
                <h1>Ana Uygulama</h1>
                <Modal>
                    <h2>Bu bir modal</h2>
                </Modal>
            </div>
        );
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
Dangerously Set InnerHTML

React, XSS (cross-site scripting) saldırılarına karşı koruma sağlamak için HTML içeriğini varsayılan olarak eklemez. Ancak, gerektiğinde HTML içeriği doğrudan eklemek için `dangerouslySetInnerHTML` kullanabilirsiniz. Bu yöntem, güvenli olmayan içerik eklerken dikkatli olunması gerektiğini belirtir.

Örnek:

<script>
        const htmlContent = "<div style='color:red'>Bu içerik HTML olarak eklenmiştir</div>";
        
        return (
            <div dangerouslySetInnerHTML={{ __html: htmlContent }} />
        );
        </script>
Forwarding Refs

Refs'i bileşenler arasında iletmek için `React.forwardRef` kullanılır. Bu, özellikle üst bileşenden alt bileşene ref geçmek gerektiğinde kullanışlıdır.

Örnek:

<script>
        const MyInput = React.forwardRef((props, ref) => (
            <input ref={ref} type="text" />
        ));
        
        const App = () => {
            const inputRef = React.createRef();
        
            return (
                <div>
                    <MyInput ref={inputRef} />
                    <button onClick={() => inputRef.current.focus()}>Odağı Ayarla</button>
                </div>
            );
        };
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>
useImperativeHandle Hook'u

`useImperativeHandle` hook'u, refs ile erişildiğinde bileşenin iç durumu hakkında kontrol sağlayan işlevler tanımlamak için kullanılır.

Örnek:

<script>
        const MyInput = React.forwardRef((props, ref) => {
            const inputRef = React.useRef();
        
            React.useImperativeHandle(ref, () => ({
                focus: () => {
                    inputRef.current.focus();
                }
            }));
        
            return <input ref={inputRef} type="text" />;
        });
        
        const App = () => {
            const inputRef = React.createRef();
        
            return (
                <div>
                    <MyInput ref={inputRef} />
                    <button onClick={() => inputRef.current.focus()}>Odağı Ayarla</button>
                </div>
            );
        };
        
        ReactDOM.render(<App />, document.getElementById('root'));
        </script>

İpuçları ve En İyi Uygulamalar

  • refs kullanımı: Refs kullanırken yalnızca gerektiğinde kullanın ve bileşenlerin kontrolünü doğrudan DOM'a bırakmamaya çalışın.
  • Portals: Portals'ı, bileşenlerin DOM hiyerarşisinin dışında render edilmesi gerektiğinde kullanın, ancak genel uygulama düzenini bozmayacak şekilde yerleştirin.
  • dangerouslySetInnerHTML: Bu yöntemi kullanırken güvenlik risklerini dikkate alın ve yalnızca güvenli olduğundan emin olduğunuz içerikleri ekleyin.
  • forwarding refs: Refs'i bileşenler arasında geçirirken, bileşenlerin iç işleyişini gizlemeye özen gösterin ve yalnızca gerekli fonksiyonları dışa açın.
  • useImperativeHandle: Bu hook'u kullanarak bileşenlerin iç işleyişini kontrol etmek için gerekli işlevleri tanımlayın, ancak bileşenin kullanımını karmaşık hale getirmemeye dikkat edin.
